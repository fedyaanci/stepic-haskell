```hs
sieve :: [Integer] -> [Integer] {сигнатура типа}
```
sieve - такая функция, которая принимает список целочисленных типа Integer, возвращает также список Integer 

sieve(x:xs) = x : sieve [y | y <- xs, y `mod` x /= 0]
###### у любого непустого списка есть голова (первый элемент) и хвост
```
sieve(x:xs) - x-обозначение головы, а xs - обозначение хвоста
`mod` - обратные кавычки нужны, чтобы использовать функцию как оператор.
[...] - возьми каждое y из списка xs, но оставь те, которые при делении на x не дают остатка 0
```
В этом блоке мы создаем список, где вычеркиваем все числа, кратные x.

... = x : sieve[...] - тут вызываем рекурсивно функцию sieve для нового отфильтрованного списка
